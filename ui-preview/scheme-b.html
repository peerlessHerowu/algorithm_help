想象你在一堆硬币中找到两枚面值加起来刚好等于某个数的组合。暴力做法是每枚都跟其他所有硬币比一遍 —— 但如果你有一本"账本"，就能一次扫描搞定。

def twoSum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        diff = target - num
        if diff in seen:
            return [seen[diff], i]
        seen[num] = i
