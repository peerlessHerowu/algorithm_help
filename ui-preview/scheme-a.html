🎯 L3 技术解析

问题本质：给定整数数组 nums 和目标值 target，找出和为 target 的两个元素的下标。

关键洞察：对每个 nums[i]，我们需要找到 target - nums[i] 是否存在。哈希表提供 O(1) 查找，将整体复杂度从 O(n²) 降到 O(n)。

边界处理：同一元素不能使用两次 → 先查后存。数组可能有重复值 → 哈希表存最新下标即可。

def twoSum(nums: List[int], target: int) -> List[int]:
    seen = {}  # key: 数值, value: 下标
    for i, num in enumerate(nums):
        diff = target - num
        if diff in seen:
            return [seen[diff], i]
        seen[num] = i
    return []  # 题目保证有解，不会到这里

💎 底层共同思路

本质：所有解法的共同本质是"在集合中查找互补元素"——遍历时对每个元素寻找一个"配对"。暴力用 O(n) 扫描找配对，排序后用二分/双指针找，哈希表用 O(1) 查找找。

🧭 框架迁移：这个"查找互补"框架可推广到 → 三数之和（固定一个找两个互补）→ 子数组和（前缀和+找互补）→ 数对计数（哈希表统计频率）

🪟 滑动窗口

模式描述

滑动窗口是一种用于处理连续子数组/子串问题的技巧。通过维护一个动态窗口（通常用左右指针表示），避免重复计算，将 O(n²) 降到 O(n)。适用于求最长/最短满足条件的子串/子数组。

🎯 识别信号

✓题目要求连续子数组/子串
✓求最长/最短/恰好满足某条件
✓可以通过"扩大窗口"和"缩小窗口"来维护条件
✗子序列（不连续）问题通常不适用
📋 通用模板 📋 复制 
def sliding_window(s):
    left = 0
    window = {}  # 窗口内状态
    result = 0
    
    for right in range(len(s)):
        # 1. 扩大窗口
        window[s[right]] = window.get(s[right], 0) + 1
        
        # 2. 收缩条件
        while 窗口不满足条件:
            window[s[left]] -= 1
            left += 1
        
        # 3. 更新答案
        result = max(result, right - left + 1)
    
    return result
