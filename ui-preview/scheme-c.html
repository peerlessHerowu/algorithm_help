直觉建立

想象你在一堆硬币中找到两枚面值加起来刚好等于某个数的组合。暴力做法是每枚都跟其他所有硬币比一遍 —— 但如果你有一本"账本"记住已经看过的硬币，就能一次扫描搞定。

核心思路

遍历数组，对每个元素计算"差值"，然后去哈希表中查找这个差值是否已存在。

关键洞察：本质是"在集合中查找互补元素"。哈希表将查找从 O(n) 降到 O(1)。
Python 复制 
def twoSum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        diff = target - num
        if diff in seen:
            return [seen[diff], i]
        seen[num] = i
