哈希表一次遍历法

使用哈希表记录已遍历的数字，将 O(n²) 优化到 O(n)

▶

🧩 模式识别

所属模式：哈希表查找
识别信号：在数组中找满足条件的配对 → 想到"补数查找"
核心洞察：不需要找到所有配对再筛选，而是边遍历边查找

💡 核心思路

遍历数组时，对每个 nums[i]， 计算 complement = target - nums[i]。 如果 complement 已在哈希表中 → 找到答案。否则存入哈希表继续。 

class Solution:
    def twoSum(self, nums, target):
        seen = {}  # 存储 {数字: 索引}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
        return []
⏱️ O(n) 💾 O(n)
✨ AI 原创

双指针法（排序后对撞）

先排序，然后用左右指针从两端向中间逼近，适合理解"缩小搜索空间"的思想
