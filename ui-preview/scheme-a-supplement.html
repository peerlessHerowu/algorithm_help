合并两个有序链表 含 1 处错误

合并两个有序链表的思路是：创建一个虚拟头节点 dummy，用一个指针 curr 从 dummy 开始遍历。

每次比较两个链表头节点的值，将较大的那个 接到 curr 后面，然后移动该链表的指针。

最后某个链表为空时，把另一个剩余部分直接接上。时间复杂度 O(m+n)，空间 O(1)。

import heapq

def shortest_path(graph, start, end):
    """简化版 Dijkstra — 城市导航核心"""
    dist = {start: 0}
    pq = [(0, start)]  # (距离, 节点)
    prev = {}
    
    while pq:
        d, u = heapq.heappop(pq)
        if u == end:
            return reconstruct(prev, end)
        for v, w in graph[u]:  # 邻居和权重
            if d + w < dist.get(v, float('inf')):
                dist[v] = d + w
                prev[v] = u
                heapq.heappush(pq, (d + w, v))
    return None  # 不可达

📐 递推关系 × 动态规划

L1 L2 L3 L4 L5

核心联系：DP 中的状态转移方程本质就是数学中的递推关系（recurrence relation）。

斐波那契数列 F(n) = F(n-1) + F(n-2) 是最简单的线性递推。而 dp[i] = max(dp[j] + 1) for j < i 则是非线性递推。

可视化：递推关系 → 递归树展开 → 发现重叠子问题 → 用表格记忆化。
