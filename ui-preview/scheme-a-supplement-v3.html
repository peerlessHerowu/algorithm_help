重叠子问题 → 缓存层设计

DP 中的 memo 数组本质和 Redis 缓存是同一个思想："如果之前算过，就不再算了"。在工作中设计多级缓存（L1 内存 → L2 Redis → L3 数据库）时，你其实在做的就是"把已知子问题的答案存起来"。

# DP memo 版本
memo = {}
def fib(n): return memo.setdefault(n, fib(n-1)+fib(n-2))
