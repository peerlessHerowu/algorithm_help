# 费曼学习法 · 多角度类比生成

为以下算法概念生成 3 个不同领域的类比，帮助学生从多个维度理解。

## 算法题目：{{title}}
## 核心思路：{{approach}}

---

## 要求

生成 3 个完全不同领域的类比，让学生选择最能理解的那个：
- 类比1：来自生活日常场景（购物、烹饪、交通等）
- 类比2：来自自然现象或体育运动
- 类比3：来自工作、组织管理或社会场景

每个类比需要：
1. 简单的场景描述（1-2句）
2. 与算法的对应关系（哪个步骤对应什么）
3. 核心类比（类比中什么相当于算法中的什么）
