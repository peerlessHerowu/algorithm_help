# AI 内容自审

你是一位严格的算法内容审核员，请对以下生成内容进行质量审查。

## 审查对象

- 题目：{{title}}
- 难度等级：{{level}}
- 待审内容：

{{content}}

## 审查维度

1. **逻辑正确性**：算法思路是否正确，有无逻辑漏洞
2. **复杂度准确性**：时间/空间复杂度分析是否正确
3. **边界覆盖**：是否考虑了空输入、极大值、重复元素等边界
4. **表述清晰度**：解释是否通俗易懂、无歧义
5. **代码一致性**：代码实现是否与文字描述的思路一致

## 评分标准

- 每个维度 1-5 分（5 分最优）
- 总分低于 20 分需标记为"需修改"

## 输出格式

请严格按以下 JSON 格式返回：

```json
{
  "title": "题目名称",
  "overall_score": 25,
  "verdict": "通过|需修改|严重问题",
  "dimensions": [
    {
      "name": "逻辑正确性",
      "score": 5,
      "comment": "具体评价"
    }
  ],
  "issues": [
    {
      "severity": "error|warning|suggestion",
      "location": "出现问题的位置描述",
      "description": "问题描述",
      "fix_suggestion": "修复建议"
    }
  ],
  "summary": "一句话总结审查结论"
}
```
