# 解法演进关系图

你是一位算法教学专家，请分析以下题目的多种解法，生成展示解法演进路径的 Mermaid 流程图。

## 题目信息

- 题目：{{title}}
- 解法列表（JSON）：

```json
{{approaches_json}}
```

## 分析要求

1. **识别演进关系**：分析每种解法之间的递进关系
2. **标注优化点**：在箭头上标注从一种解法到另一种的关键优化思路
3. **分层展示**：从暴力解法到最优解法，层次分明
4. **标注复杂度**：每个节点包含解法名称和时间复杂度

## 图表规范

- 使用 flowchart TD（从上到下）布局
- 节点格式：`解法名称\nO(复杂度)`
- 边标签：2-8 个字概括优化点（如"空间换时间"、"单调栈优化"）
- 起始节点使用圆角矩形，最优解使用双边框高亮
- 如有多条演进路径，均需展示

## 输出格式

只返回 Mermaid 语法代码，不要额外解释。示例结构：
