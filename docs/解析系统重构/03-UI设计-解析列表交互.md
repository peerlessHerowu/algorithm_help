## 二、解析列表设计（核心交互）

### 2.1 CollapsibleCard（收起态）

```
┌─ 16px 圆角 ──────────────────────────────────────────────┐
│                                                          │
│  🏷️ 基于社区题解          标题文字（headline 17px/600）    │
│                                                          │
│  摘要文本（body 15px/400，最多 2 行，text-secondary）     │
│                                                          │
│  ┌─────┐ ┌─────┐ ┌──────┐           ★ 5,674  ▶        │
│  │Hash │ │O(n) │ │Python│                               │
│  └─────┘ └─────┘ └──────┘                               │
│  (标签胶囊 8px圆角 bg-secondary)                          │
│                                                          │
└──────────────────────────────────────────────────────────┘
 shadow-sm，Hover 时 shadow-md + scale(1.01)
 按下时 scale(0.98) + opacity(0.9)
```

**视觉规格：**
- 卡片背景：`bg-white/80 dark:bg-gray-900/80`（半透明 + backdrop-blur）
- 圆角：16px
- 边框：`border border-gray-200/50 dark:border-gray-700/50`
- 内边距：20px
- 卡片间距：12px
- 阴影：默认 shadow-sm，hover shadow-md
- 展开指示器（▶）：右侧，12px，text-tertiary

### 2.3 展开/收起动画

```css

  max-height: 0;
  opacity: 0;

  max-height: 5000px; /* 足够大 */
  opacity: 1;

  transition: transform 250ms cubic-bezier(0.22, 1, 0.36, 1);
}
.chevron-expanded {
  transform: rotate(90deg);
```

## 十、加载策略与性能优化

### 10.1 列表数据加载

```
列表页（收起态）：只请求摘要数据（title + summary + tags）
展开卡片时：lazy load 详情（content + codeImplementations）
切换级别时：前端缓存已加载的级别数据，避免重复请求
```

**请求时序：**
```
用户打开题目页 → GET /enriched/{id}/level/3 (摘要列表)
用户点击展开卡片 → GET /enriched/{solutionId}/detail (完整内容)
用户切换到 L4 → GET /enriched/{id}/level/4 (摘要列表)
用户切回 L3 → 命中前端缓存，不请求
```

### 10.2 重组件按需渲染

| 组件 | 策略 |
|------|------|
| LaTeX 公式 | Intersection Observer，进入视口才用 KaTeX 渲染 |
| Mermaid 图 | Intersection Observer，进入视口才渲染 |
| 代码高亮 | 只渲染当前选中语言 Tab，切换时才渲染其他 |
| 图片/SVG | native lazy loading (`loading="lazy"`) |

### 10.3 快捷导航

- 展开多条卡片后，右侧浮动显示 mini 目录（各卡片标题锚点）
- 「回到顶部」按钮在滚动超过 600px 时出现
- sticky header 显示当前级别标签（滚动时固定）

```
└─────────────────────────────────────────────────────────┘
```

- 样式：金色边框 `border-amber-300`
- 摘要后追加一行「社区评价最高，推荐优先阅读」

### 11.2 筛选能力（AI 深度解析 Tab 内）

```
┌──────────────────────────────────────────────────────┐
│  解法标签：[全部] [哈希表] [双指针] [暴力] [排序]    │
└──────────────────────────────────────────────────────┘
```

- 标签来自 enriched_solutions.tags 字段
- 点击后只显示包含该标签的卡片
- 与级别选择器并列，不互斥
