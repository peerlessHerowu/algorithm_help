## 一、产品定位

### 1.1 核心价值

```
学习 → 遗忘 → 再学习（低效循环）
               ↕
学习 → 遗忘曲线调度复习 → 长期记忆（高效闭环）

间隔重复的核心洞察（Ebbinghaus，1885）：
  在遗忘临界点之前复习，记忆巩固效率最高。
  分散复习比集中复习长期保持效果好。
```

成就系统的目标不是"游戏化"，而是：
1. 让用户看到自己的真实进步（里程碑可视化）
2. 正向强化持续学习行为
3. 适当的社区氛围（飘屏）而不过度打扰

CREATE TABLE review_records (
    id              BIGINT       AUTO_INCREMENT PRIMARY KEY,

### 2.2 SM-2 算法实现

```java
@Service
public class SM2Scheduler {

    /**
     * 根据用户自评更新卡片调度参数
     *
     * quality 映射（来自 PRD Req 25）：
     *   😟 忘了    → quality = 1
     *   🤔 模糊    → quality = 3
     *   😊 记得    → quality = 4
     *   🚀 秒杀    → quality = 5
     */
    public SM2Result update(SpacedRepetitionCard card, int quality) {
        float ef = card.getEf();
        int repetitions = card.getRepetitions();
        int interval = card.getIntervalDays();

        if (quality < 3) {
            // 忘了 → 重置，从头开始
            repetitions = 0;
            interval = 1;
        } else {
            // 记住了 → 更新间隔
            if (repetitions == 0) {
                interval = 1;
            } else if (repetitions == 1) {
                interval = 6;
            } else {
                interval = Math.round(interval * ef);
            }
            repetitions++;
        }

        // 更新 EF（难易因子），范围 [1.3, ∞)
        ef = ef + (0.1f - (5 - quality) * (0.08f + (5 - quality) * 0.02f));
        ef = Math.max(1.3f, ef);

        long nextReviewAt = Instant.now()
            .plus(interval, ChronoUnit.DAYS)
            .toEpochMilli();

        return SM2Result.builder()
            .newEf(ef)
            .newInterval(interval)
            .newRepetitions(repetitions)
            .nextReviewAt(nextReviewAt)
            .build();
    }

    /**
     * 预估下次复习时间（用于 hover tooltip 显示）
     */
    public String estimateNextInterval(float ef, int currentInterval, int quality) {
        SM2Result r = update(
            SpacedRepetitionCard.builder().ef(ef).intervalDays(currentInterval)
                .repetitions(1).build(), quality);
        int days = r.getNewInterval();
        if (days == 1) return "明天";
        if (days <= 7) return days + "天后";
        if (days <= 30) return (days / 7) + "周后";
        return (days / 30) + "个月后";
    }
}
```

### 2.4 四种复习方式实现

#### 方式1：讲解思路（explain）
用户对着题目默想/写出解题思路，然后与 AI 总结对比。

```
前端：展示题目 → 用户输入思路 → 点击"查看标准思路"
      → 双栏对比（你的思路 vs 标准思路）→ 自评
```

#### 方式2：补全代码（code_complete）
展示带空位的代码框架，用户填写关键行。

```
数据来源：GET /api/v1/review/code-completion?cardId={id}
返回：{
  code: "def two_sum...\n    need = ___\n    ...",
  blankLines: [{line: 4, hint: "计算目标值与当前值的关系"}],
  answer: "target - n"  // 不发给前端
}

AI 验证语义正确性：
POST /api/v1/review/code-completion/check
{
  cardId, userAnswer: "t - n"
}
→ {"correct": true, "standardAnswer": "target - n", "explanation": "语义一致"}
```

#### 方式3：看图猜算法（visual_quiz）
展示 Mermaid/图解图片（隐藏标题），用户从候选算法中选择。

```
数据来源：GET /api/v1/review/visual-quiz?count=1
返回：{
  diagram: "graph LR\n  A[2] --> B[4] --> C[3]...",  // Mermaid
  diagramType: "linked_list",
  options: ["双指针", "链表模拟", "哈希表", "动态规划"],
  correctIndex: 1
}
```

#### 方式4：模式识别（pattern_quiz）
与训练页面相同，但题目来自用户的待复习卡片池。

### 4.2 成就检查服务

```java
@Service
@RequiredArgsConstructor
public class AchievementCheckService {

    private final AchievementRepository achievementRepo;
    private final NotificationService notificationService;

    /**
     * 完成题目时检查
     */
    public void checkOnProblemComplete(UUID userId, String problemId) {
        checkFirstProblem(userId);
        checkStreaks(userId);
        checkPatternMaster(userId, problemId);
    }

    /**
     * 复习完成时检查
     */
    public void checkOnReviewComplete(UUID userId) {
        checkFirstReview(userId);
        checkStreaks(userId);
        checkComplexityMaster(userId);
    }

    /**
     * 费曼会话完成时检查
     */
    public void checkOnFeynmanComplete(UUID userId) {
        long feynmanCount = sessionRepo.countByUserIdAndType(userId, "feynman");
        if (feynmanCount == 5)  unlock(userId, FEYNMAN_SCHOLAR_5);
        if (feynmanCount == 20) unlock(userId, FEYNMAN_SCHOLAR_20);
        if (feynmanCount == 50) unlock(userId, FEYNMAN_SCHOLAR_50);
    }

    private void unlock(UUID userId, AchievementType type) {
        if (achievementRepo.existsByUserIdAndType(userId, type)) return;

        Achievement a = Achievement.builder()
            .userId(userId).type(type).unlockedAt(now()).build();
        achievementRepo.save(a);

        // 推送成就解锁通知（SSE）
        notificationService.push(userId,
            Notification.achievementUnlocked(type));

        // 全服飘屏推送
        broadcastAchievement(userId, type);
    }
}

// 前端：监听 SSE 成就飘屏事件
const useBroadcastAchievement = () => {
  const [banners, setBanners] = useState<BroadcastBanner[]>([]);

  useEffect(() => {
    const es = new EventSource('/api/v1/users/me/notifications/stream');
    es.addEventListener('BROADCAST_ACHIEVEMENT', (e) => {
      const data = JSON.parse(e.data);
      setBanners(prev => {
        // 最多同时显示 2 条
        if (prev.length >= 2) return prev;
        return [...prev, { ...data, id: Date.now() }];
      });
      // 5秒后自动移除
      setTimeout(() => {
        setBanners(prev => prev.filter(b => b.id !== Date.now()));
      }, 5000);
    });
    return () => es.close();
  }, []);

  return banners;
};

## 七、测试方案

```
SM-2 算法单元测试：
  - 初始卡片，quality=5 → interval=1天
  - 第2次 quality=5 → interval=6天
  - 第3次 quality=5 → interval=Math.round(6 × 2.5)=15天
  - quality=1 → 重置，interval=1天
  - EF 下限：连续 quality=1 后 EF 不低于 1.3

成就检查测试：
