## 三、用户旅程 Review（站在用户角度走一遍）

### 3.1 新用户首次体验

```
访问首页 → 看到 Hero("算法深度理解引擎") → 点击"开始学习"
  → 进入题目列表 → 选择"两数之和" → 进入详情页(L3)
  → 阅读完毕 → ❌ 流程断裂，不知道下一步做什么
```

**问题**：阅读完一道题后没有引导。
**建议**：内容末尾加"下一步"引导区域（NEW-2 已记录）。

### 3.2 面试准备者旅程

```
登录 → 想按"Google面试"筛选题目 → ❌ 题目列表无公司标签筛选
  → 手动浏览找到相关题 → 学习 L3/L4 → 想做面试模拟
  → 进入面试页 → ❌ 无法选择"Google风格/45分钟"
  → 面试结束看到评分报告 → 想针对薄弱点训练 → ❌ 无跳转路径
```

**问题**：
1. 公司标签筛选 UI 缺失（NEW-5 关联）
2. 面试配置面板缺失（NEW-8）
3. 评分报告 → 薄弱点训练的跳转路径不存在

**建议**：评分报告的低分维度加"针对训练"按钮，跳转到对应模式训练。


### 3.3 日常复习者旅程

```
登录 → 首页看到和匿名用户一样的 Hero → ❌ 没有"今日5道待复习"入口
  → 手动点击导航进"复习中心" → 翻卡片复习 → 自评
  → 完成 → ❌ 无正向激励("太棒了！今日完成 🎉")
  → 离开 → 次日回来 → ❌ 不确定是从头开始还是继续
```

**问题**：
1. 首页无个性化"今日复习"入口（NEW-1）
2. 复习完成无正向反馈/庆祝动画
3. 中途退出后恢复逻辑不明确

**建议**：
- 已登录首页展示 Dashboard 而非 Hero
- 全部完成时播放 confetti 动画 + "今日完成"徽章
- 复习进度持久化到后端，中途退出可继续

### 3.4 内容生成触发旅程

```
进入某题详情 → 发现 L4 未生成 → 看到锁定态"🔒 L5 论文"
  → ❌ L4 也没有"触发生成"按钮，只是 Tab 灰色
  → 用户不知该怎么获取 L4 内容 → 放弃
```

**问题**：未生成级别的空状态缺少行动引导。
**建议**：点击灰色 Tab 时展示"此级别尚未生成"+ 🚀 按钮。


### 3.5 错误恢复旅程

```
用户在费曼对话中，网络突然断开
  → ❌ 无任何提示，消息发不出去
  → 用户刷新页面 → ❌ 对话历史丢失？还是保存了？
```

**问题**：
1. WebSocket 断线无 UI 反馈
2. 对话恢复机制对用户不透明

**建议**：
- 顶部 Banner "网络断开，正在重连..."
- 重连成功后恢复上下文并提示"已恢复"
- 费曼/面试页本地缓存最近输入（防丢失）

| UI 功能 | 所在 HTML | 缺少的 Spec 定义 | 建议补充位置 |

| 模式识别训练页面 | scheme-a-supplement | PatternQuiz 组件定义 + 前端路由 | Spec3 web-presentation-layer |

### 4.3 需要新增到 Spec 的数据模型

以下实体/API 在 UI 中已有交互但 Spec design 中未完整定义：

1. **AchievementCheckService** — 触发条件规则引擎（何时检查？用事件驱动还是定时扫描？）
2. **DailyPlanService** — 每日计划生成逻辑（何时生成？凌晨定时？用户首次访问时？）
3. **ComplexityTrainingService** — 题目生成 + 答案校验 + 统计
4. **BroadcastService** — SSE 推送 vs WebSocket？与已有通知通道的关系

## 五、逻辑自洽性检查

### 5.1 数据一致性

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 首页"500+题目"vs MVP 50题 | ⚠️ 不一致 | 建议改为动态数字或"50+精选深度解析" |
| 模式卡片"掌握度75%"数据来源 | ⚠️ 不明确 | 需定义：掌握度 = 该模式已完成题数/总题数 × 正确率加权 |
| 面试评分"78/100 · B+"评级标准 | ⚠️ 未定义 | 需在 Spec4 中补充评级映射表（A+/A/B+/B/C） |
| 复习"记忆保持率68%"计算方式 | ⚠️ 未定义 | 需在 Spec4 中定义：保持率 = 复习时 quality≥3 的比例 |

### 5.2 状态转移完整性

| 实体 | 定义的状态 | UI 是否覆盖全部状态 | 缺失 |
|------|-----------|-------------------|------|
| Explanation | GENERATING → PENDING_REVIEW → PUBLISHED / REJECTED → ARCHIVED | 部分 | 缺 REJECTED 和 ARCHIVED 的前端展示 |
| InterviewState | IDLE → PROBLEM_SOLVING → FOLLOW_UP → CODING → VARIANT → SCORING | 部分 | 缺 VARIANT 阶段的 UI |
| SessionStatus | ACTIVE → PAUSED → COMPLETED → EXPIRED | 部分 | 缺 EXPIRED 的用户提示弹窗 |

### 5.3 权限逻辑

| 场景 | 期望行为 | UI 是否体现 |
|------|----------|-------------|
| 匿名用户点"触发生成" | 弹出登录提示 | ❌ 未展示 |
| 匿名用户点"费曼模式" | 弹出登录提示 | ❌ 未展示 |
| 普通用户访问 /admin | 403 或重定向 | ❌ 未展示错误页 |
| Token 过期 | 静默刷新或弹出登录框 | ❌ 未展示 |

## 七、让人"眼前一亮"的设计机会

### 7.1 即时反馈微交互（推荐实现）

| 场景 | 效果 |
|------|------|
| 切换 Level Tab | 内容方向性 slide 动画（升级↑/降级↓） |
| 收藏成功 | 星星弹性放大 + 金色粒子 |
| 复习自评"秒杀" | 卡片飞出 + confetti 庆祝 |
| 连续学习 7 天 | Logo 旁出现 🔥 火焰动画 |
| 生成完成 | 内容渐入 + Mermaid "绘制"路径描边动画 |


### 7.2 沉浸式学习模式

- **专注模式**：隐藏导航+侧边栏，只留内容+TOC，快捷键 `Esc` 退出
- **阅读进度**：页面右侧极细蓝色进度线（类 Medium）
- **代码跟随高亮**：阅读到"第3步"时，代码对应行自动高亮

### 7.3 个性化"学习 DNA"

- 个人中心展示"学习 DNA"图：将用户偏好（擅长模式/级别/时段）生成艺术化图形
- 分享功能：生成精美"我的算法学习报告"卡片

### 7.4 细节打磨建议

| 场景 | 当前 | 建议 |
|------|------|------|
| 空列表 | 纯文字"未找到" | 加插画 + 建议操作 |
| 加载中 | 无骨架屏 | 每个页面补 Skeleton Loading |
| 首次使用 | 无引导 | 关键页面首次访问加 Tooltip 引导 |
| 错误页 | 未设计 | 统一 404/500/429 错误页（含重试+反馈链接） |
