# UI 设计规范 — 方案C：Notion 文档风

> 风格对标：Notion / Obsidian Publish / GitBook / Cal.com
> 设计理念：**内容即界面，排版即设计，阅读即享受**

---

## 一、设计哲学

### 核心气质

```
温暖 · 专注 · 文学性 · 呼吸感 · 沉浸阅读 · 纸质感
```

像一本精心排版的技术书籍 — 内容本身就是最好的设计，UI 完全退居幕后。

### 三条原则

| 原则 | 描述 |
|------|------|
| **排版即设计** | 通过字体、行距、留白制造高级感，而非视觉装饰 |
| **中性色统治** | 90%的页面是黑白灰+暖米色，彩色只在功能处出现 |
| **纸质触感** | 微妙的纹理、柔和的圆角、温暖的底色，像高级纸张 |

## 二、色彩系统

### 2.1 亮色模式（默认）

| Token | 值 | 说明 |
|-------|-----|------|
| `--bg-root` | `hsl(40 20% 98%)` | 温暖米白（不是冷白） |
| `--bg-primary` | `hsl(0 0% 100%)` | 纯白卡片 |
| `--bg-secondary` | `hsl(40 15% 95%)` | 代码块/引用底色 |
| `--bg-hover` | `hsl(40 10% 93%)` | Hover 状态 |

### 2.2 文字

| Token | 值 | 说明 |
|-------|-----|------|
| `--text-primary` | `hsl(0 0% 12%)` | 深灰黑（不用纯黑） |
| `--text-secondary` | `hsl(0 0% 44%)` | 次要信息 |
| `--text-tertiary` | `hsl(0 0% 62%)` | 最弱信息 |

### 2.3 强调色（一抹暖橘）

| Token | 值 | 用途 |
|-------|-----|------|
| `--accent` | `hsl(24 85% 55%)` | 暖橘色，链接/选中 |
| `--accent-subtle` | `hsl(24 85% 55% / 0.1)` | 标签底色 |

### 2.4 暗色模式

| Token | 暗色值 |
|-------|--------|
| `--bg-root` | `hsl(30 5% 10%)` |
| `--bg-primary` | `hsl(30 5% 13%)` |
| `--bg-secondary` | `hsl(30 5% 16%)` |
| `--text-primary` | `hsl(40 10% 88%)` |

### 2.5 难度色（饱和度降低版）

| 难度 | 颜色 | 说明 |
|------|------|------|
| Easy | `hsl(150 40% 40%)` | 沉稳绿 |
| Medium | `hsl(35 70% 50%)` | 暖琥珀 |
| Hard | `hsl(0 50% 50%)` | 柔红 |

## 三、字体系统

```css
--font-sans: 'Source Serif 4', 'Noto Serif SC', Georgia, serif;
--font-body: 'Inter', 'Noto Sans SC', sans-serif;
--font-mono: 'IBM Plex Mono', monospace;
```

> 标题用衬线体（Source Serif 4），正文用无衬线（Inter）。
> 衬线标题 + 无衬线正文 = 经典书籍排版，天然高级。

### 字号阶梯

| Token | 大小 | 行高 | 字体 |
|-------|------|------|------|
| `--text-sm` | 14px | 22px | body |
| `--text-base` | 16px | 28px | body |
| `--text-lg` | 20px | 32px | serif |
| `--text-xl` | 26px | 36px | serif |
| `--text-2xl` | 34px | 44px | serif |
| `--text-3xl` | 44px | 52px | serif |

> 正文行高 1.75（28/16），比常规更大，阅读体验极佳。

## 四、间距与留白

### 核心理念：大量留白

| 区域 | 规则 |
|------|------|
| 内容最大宽度 | **680px**（比其他方案更窄，极致阅读） |
| 段落间距 | 32px |
| 标题上方 | 64px（一级标题）/ 48px（二级） |
| 页面顶部留白 | 120px |
| 行间距 | 1.75em |

### 间距阶梯

```
4  8  12  16  24  32  48  64  96  128
```

## 五、动效系统

### 极简动效

这个方案的动效是四种中**最克制的** — 几乎静止，只在必要时有微弱反馈。

| 交互 | 动效 |
|------|------|
| 链接 Hover | 下划线从左到右展开（200ms） |
| 卡片 Hover | 底色变暖（bg-hover）+ 无位移 |
| Tab 切换 | 仅 opacity 渐变(150ms)，无滑动 |
| 页面切换 | 整页 opacity 0→1 (300ms) |
| 代码复制 | 图标变✓，无额外动画 |

### 禁忌

- ❌ 没有任何上浮/缩放/弹性效果
- ❌ 没有发光/阴影变化
- ❌ 一切都是"安静的变化"

## 六、组件风格

### 6.1 按钮

```
Primary:   accent背景 + 白色文字 + 6px圆角 + 无阴影
Secondary: 透明 + border(1px solid灰) + hover底色变暖
Text:      仅文字链接样式 + 下划线hover动画
```

### 6.2 LevelTabs

**设计**：书签标签页风格

```
容器: 底部有一条细灰线
每个Tab: 像书页标签，顶部有小圆角
选中: 白色背景 + 底部灰线断开 + 衬线字体加粗
未选中: 透明 + text-secondary
未生成: italic斜体 + "..."后缀
```

### 6.3 卡片

```
背景: bg-primary(纯白)
边框: 无（靠底色对比制造层次）
圆角: 8px
阴影: 极淡(0 1px 3px rgba(0,0,0,0.04))
Hover: 底色微变暖
```

### 6.4 CodeBlock

```
背景: bg-secondary(温暖灰)
边框: 无
圆角: 6px
左侧: 3px 竖线(accent色)
字体: IBM Plex Mono, 14px
行号: 无（更简洁）
```

### 6.5 正文排版

```
段落: 首行不缩进，段间32px
引用: 左侧4px暖橘竖线 + 斜体
列表: 小圆点使用accent色
表格: 极简横线表格（无竖线、无背景色）
```

---

## 七、页面装饰

### 极简装饰

- 页面顶部：一条细的渐变线（accent色从左到右渐隐）
- 页脚：无装饰，仅文字
- 背景：纯色或极淡的纸质纹理（noise texture, opacity 0.02）

---

## 八、布局

### 单栏为主

```
┌──────────────────────────────────────────┐
│  Navbar (极简: Logo + 几个文字链接)        │
├──────────────────────────────────────────┤
│                                          │
│           Main Content                   │
│          (max-w: 680px)                  │
│           居中排列                        │
│                                          │
│    [TOC 在内容上方折叠，                   │
│     点击展开为侧栏]                       │
│                                          │
└──────────────────────────────────────────┘
```

- 默认单栏居中（像博客文章/书籍）
- TOC 可选展开为右侧边栏
- 移动端无变化（本身就是单栏）

---

## 九、风格总结

**一句话定义**：纸质温暖 × 衬线优雅 × 极致留白 × 专注阅读

适合追求"内容质量"的用户。视觉上最不"炫"，但阅读体验最好。像一本排版精美的 O'Reilly 技术书。可能不是第一眼惊艳，但用久了会觉得"这才是正确的方式"。
