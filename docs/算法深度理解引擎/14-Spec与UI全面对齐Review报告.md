## 三、用户体验流程审查（站在用户角度）

### 1. 新用户首次访问流程

```
首页 Hero → 点击"开始学习" → 题目列表 → 点击某题 → 题目详情(L3) → 阅读完 → 下一步引导
```

**评价：✅ 顺畅**。路径清晰，每步都有明确引导。首页 CTA 直达题目列表，详情页底部有"下一步"区域。

**改进点：**
- 首页"快速体验"入口（R18.5）仅在 Spec 中，UI 未明确展示一个"不注册直接看最热题"按钮位置
- 建议：Hero 区增加"先看一道 → Two Sum"的次要入口

### 2. 已注册用户日常学习流程

```
登录 → Dashboard(今日计划/继续学习/待复习) → 执行今日计划 → 复习中心翻卡 → 完成
```

**评价：✅ 逻辑自洽**。Dashboard 三卡片提供了清晰入口。

**改进点：**
- Dashboard 的"基于薄弱模式推荐"数据来源未在 API spec 中明确（需后端配合）
- 建议：在 R1.6 中补充"推荐算法"来源说明

### 3. 费曼学习模式流程

```
题目详情 → 点击"费曼模式" → 实时对话 → AI追问 → 用户回答 → 理解评估面板更新 → 结束生成总结
```

**评价：✅ 体验好**。右侧面板实时反馈掌握状态，让用户知道还缺什么。历史会话列表方便恢复。

**改进点：**
- UI 展示了"多类比选择"面板（字典/拼图/超市），但 Spec 中无对应需求
- 建议：新增 R12.14 描述费曼模式的"类比视角切换"功能

### 4. 面试模拟流程

```
配置面板(难度/时长/风格) → 开始面试 → 限时对话+写代码 → 结束 → 评分雷达图+改进建议
```

**评价：✅ 完整**。配置面板覆盖常见场景，评分报告六维度够细。

**改进点：**
- R12.11 提到"查看历史评分趋势"入口，UI 中有评分详细但未展示历史趋势图
- 建议：面试报告页底部增加"📈 历史趋势"折线图（显示最近 10 次评分变化）

### 5. 复习中心流程

```
复习中心 → 选择方式(翻卡/补全代码/看图猜) → 逐张复习 → 自评 → 完成激励弹窗
```

**评价：✅ 多样化复习方式是亮点**。自评按钮 tooltip 展示间隔很贴心。

**改进点：**
- "补全代码"和"看图猜模式"在 Spec R25 中有描述，但 UI 仅展示了 Tab 按钮，未展示完整交互
- 建议：后续补充"补全代码"模式的完整 UI 设计

### 6. 学习路径流程

```
学习路径列表 → 选择"DP从入门到精通" → 看进度+节点列表 → 点击当前节点 → 跳转题目详情
```

**评价：✅ 视觉清晰**。✅/🔵/🔒 三态节点一目了然，里程碑🏆标记有仪式感。

**改进点：**
- 路径的"推荐下一步"按钮（R26.5）在 UI 已有"继续学习→"
- 锁定节点是否必须按顺序解锁？Spec 未明确说明"锁定策略"
- 建议：R26 补充"节点解锁规则"说明（前置完成即解锁 vs 严格顺序）

### 7. 匿名用户转化流程

```
匿名浏览 5 题 → 底部 Banner 出现 → 点击收藏触发弹窗 → 登录 → 自动完成收藏操作
```

**评价：✅ 非侵入式设计好**。延迟操作恢复机制 R18.3 是亮点。

**改进点：**
- UI 弹窗展示了"支持 GitHub/Google 一键登录"，但注册表单页仅有 GitHub/Google 按钮
- 需确认 OAuth 登录是 MVP 还是后续功能

## 四、逻辑自洽性检查

### ✅ 自洽的部分

1. **级别系统一致**：L1-L5 在 LevelTabs、设置默认级别、生成触发、MarkdownRenderer 样式映射中保持一致
2. **认证守门一致**：未登录时费曼/面试/收藏/生成都触发登录弹窗，一致的拦截行为
3. **状态流转一致**：未生成→生成中→已生成→待修正，四态在列表页和详情页均有体现
4. **数据闭环**：费曼对话→生成总结→可转为用户题解（data-mgmt 页有费曼转题解）

### ⚠️ 逻辑不自洽/未闭合的点

| # | 问题 | 影响 | 建议 |
|---|------|------|------|
| 1 | 模式卡片展示"掌握度 75%"，但 Spec 未定义掌握度计算公式 | 用户看到数字但不知道怎么算的 | R4 补充掌握度算法说明 |
| 2 | 通知铃铛展示"3条未读"，但无通知系统 Spec | 有 UI 无后端支持 | 新增通知系统 Requirement |
| 3 | 设置页有"每日复习提醒 09:00"，但无推送机制 Spec | 功能不可实现 | 依赖 PWA Push 或邮件，需明确 |
| 4 | 苏格拉底追问（R12.1 提到）无独立 UI 页面 | 仅有入口按钮，缺交互设计 | 补充苏格拉底页面 UI 或合并到费曼模式 |
| 5 | R13.5 "学习水平自测"入口在设置增强 UI 中有展示，但无自测页面 UI | 点击后跳到哪？ | 补充自测页面 UI |
| 6 | 跨域映射表在 supplement-v3 有完整 UI，但无 Spec 需求和路由 | 实现时无参照 | 新增 R35 或挂在 R4.2 下 |
| 7 | 版本历史回滚功能（回滚弹窗）无权限校验描述 | 谁能回滚？ | Spec 明确"仅 ADMIN 可回滚" |

## 六、亮点设计总结

1. **五级深度切换 + 视觉样式差异化**：L1 大字故事→L5 紧凑学术，用户体感明显不同
2. **费曼模式实时理解评估面板**：右侧实时标注掌握/部分/未涉及，引导方向感强
3. **跨域迁移映射表**：将 DP 等抽象概念映射到工作/AI/生活场景，深化理解
4. **算法考古时间线**：赋予算法温度和故事性，记忆加深
5. **论文桥梁步骤式路径**：从 BFS 到 GraphSAGE 的渐进桥梁，学术入门友好
6. **延迟操作恢复机制**：未登录用户操作被记录，登录后自动恢复
7. **⌘K 全局搜索**：类 VS Code 体验，快速跳转任意页面
8. **面试配置面板**：公司风格/时长/难度可定制，贴近真实面试

## 七、待补充到 Spec 的新 Requirements 清单

以下是 UI 中已设计但 Spec 未覆盖的功能，需新增 Requirement：

### R31: 用户题解系统

**User Story:** As a 学习者, I want 在题目详情页查看和发布自己的题解, so that 我能学习他人思路并分享自己的理解。

**关键 AC：**
1. 题目详情页新增"📝 用户题解"Tab（与"官方解析"/"评论"三区并列）
2. 支持精选/最新/最热三种排序
3. 题解来源标记：用户原创 / URL 导入 / 费曼产出
4. 精选题解有⭐标识，由管理员标记
5. 支持 Markdown 格式的题解编写和预览
6. 题解支持点赞/评论数展示

### R32: 评论系统

**User Story:** As a 学习者, I want 对解析内容发表评论（纠错/补充/提问）, so that 内容能持续改进且能交流疑惑。

**关键 AC：**
1. 评论分四类：普通💬、纠错🐛、补充➕、提问❓
2. 纠错类评论高亮展示（红色左边框），自动通知作者
3. 补充类评论提供"展开为题解"快捷操作
4. 提问类评论支持嵌套回复
5. 评论支持点赞排序

### R33: 数据采集与映射管理（管理后台）

**User Story:** As a 管理员, I want 在后台管理数据采集任务和跨平台映射, so that 题库数据持续更新且跨平台关联准确。

**关键 AC：**
1. 支持按平台触发采集任务（LeetCode/CF/牛客/AtCoder）
2. 展示采集任务列表：运行中(进度条)/已完成/失败
3. 平台状态总览（正常🟢/已熔断🔴）
4. 跨平台映射列表：已确认/待确认，支持手动确认/驳回
5. 题目批量导入（JSON 格式，skip/update 模式）

### R34: 费曼对话转用户题解

**User Story:** As a 学习者, I want 将费曼对话的精华总结一键发布为题解, so that 我的学习成果能被他人参考。

**关键 AC：**
1. 费曼会话结束后总结面板提供"发布为题解"按钮
2. 自动提取对话中的关键思路、代码、类比作为题解草稿
3. 用户可编辑草稿后发布
4. 发布后的题解标记"费曼产出"来源

### R35: 跨域迁移映射表展示

**User Story:** As a 学习者, I want 看到算法思想在不同领域的应用映射, so that 理解算法的普适性和实际价值。

**关键 AC：**
1. 模式详情页底部展示"跨域映射表"（LeetCode/工作/AI-ML/日常生活 四列）
2. 每行可点击展开详情（含代码对比示例）
3. 数据与算法模式关联，不同模式展示不同映射内容

### R36: 全局搜索（⌘K）

**User Story:** As a 用户, I want 通过键盘快捷键呼出全局搜索面板快速跳转, so that 我不需要通过导航栏逐级点击。

**关键 AC：**
1. 支持 ⌘K (Mac) / Ctrl+K (Win) 快捷键呼出搜索面板
2. 搜索范围覆盖：题目标题、算法模式名、标签
3. 提供快速跳转入口（题目列表/算法模式/费曼/复习中心）
4. 展示最近搜索历史（本地存储）
5. ESC 关闭面板，回车跳转第一条结果

### R37: 通知系统

**User Story:** As a 用户, I want 收到系统通知（生成完成/复习提醒/新功能）, so that 我不会错过重要信息。

**关键 AC：**
1. 导航栏通知铃铛图标 + 未读数徽章
2. 点击展开通知列表面板（弹窗或侧边抽屉）
3. 通知类型：生成完成/复习提醒/系统公告/反馈回复
4. 支持标记已读/全部标记已读
5. 设置页可按类型开关通知
