## 一、产品定位与核心价值

### 1.1 为什么这是最核心的差异化

普通 AI（ChatGPT/Claude）能生成算法解析文字，但**不能让用户"看着"算法跑起来**。

这个模块要实现的是：

```
用户打开"两数之和"→ 点击 L2 级别
→ 看到：
   ① 一个数组 [2,7,11,15]，target=9
   ② 指针从左端出发，带颜色标注
   ③ 每一步变量值实时更新（i=0, nums[i]=2, need=7）
   ④ 哈希表状态随操作变化（{2:0} → 找到7！）
   ⑤ 关键决策点高亮："这里是关键——用哈希换时间"

→ 而不是：一大段描述这个过程的文字
```

**认知科学依据**（来自 04-认知科学方法论.md）：
- Mayer 多媒体学习：动画+解说比纯文字效果提升 89%
- 双重编码理论：文字+图像双通道，记忆更持久
- 代码追踪研究（ACM SIGCSE）：手动追踪变量比看讲解效果好 40%+

#### 3.1.2 走流程数据格式（TeachingSequence JSON）

AI 生成，后端存储，前端直接渲染：

```typescript
interface TeachingSequence {
  id: string;                        // UUID
  problemId: string;
  level: number;                     // 1-5
  title: string;                     // "两数相加 — 逐步演示"
  description: string;
  exampleType: 'standard' | 'boundary' | 'counterexample';
  input: string;                     // 示例输入描述
  totalSteps: number;
  estimatedDurationMs: number;

  // 初始可视化状态
  initialScene: SceneConfig;

  // 步骤列表
  steps: TeachingStep[];
}

interface TeachingStep {
  step: number;                      // 1-based
  title: string;                     // "步骤1：取出两个当前节点的值"

  // 解说
  narration: {
    text: string;                    // 20-50字
    keywords: string[];              // 高亮关键词
    isKeyDecision: boolean;          // 是否关键决策点
    keyDecisionNote?: string;        // "这是最关键的一步——用进位处理溢出"
  };

  // 动画指令列表（并行或串行）
  animations: AnimationInstruction[];

  // 变量状态（追踪表更新）
  variables: VariableState[];

  // 代码高亮（对应代码行）
  codeHighlight?: {
    language: string;
    lineStart: number;
    lineEnd: number;
  };

  // 时间控制
  duration: number;                  // 动画时长 ms
  pauseAfter: boolean;              // 关键步骤自动暂停
}

interface VariableState {
  name: string;                      // "carry"
  value: string | number | null;     // "1"
  changed: boolean;                  // 本步是否变化（高亮用）
  note?: string;                     // "进位，下一步要加上"
}
```

#### 3.2.2 图解内容规格

每个图解包含：
1. **主图**：静态或可交互的结构图
2. **图注**：每个图例说明（颜色、箭头含义）
3. **多状态切换**：关键时刻截图（"执行前" / "执行中" / "执行后"）

### 4.3 后端新增 Pipeline 步骤

在现有 enrichment pipeline 中新增两个步骤：

#### WalkthroughStep（Order 8）

```java
@Component
@Order(8)
public class WalkthroughStep implements EnrichmentStep {

    @Override
    public String getName() { return "walkthrough"; }

    @Override
    public boolean isApplicable(EnrichmentContext ctx) {
        // 必须有 polishedContent 才能生成走流程
        return ctx.getPolishedContent() != null
            && ctx.getProblem() != null;
    }

    @Override
    public EnrichmentResult process(EnrichmentContext ctx) {
        // 1. 构造 Prompt（含题目信息、解析内容、目标级别）
        String prompt = buildWalkthroughPrompt(ctx);

        // 2. 调用 AI 生成 TeachingSequence JSON
        AiResponse response = smartRouter.route(
            new AiRequest().setType(RequestType.STRUCTURED_OUTPUT)
                           .setContent(prompt)
                           .setResponseSchema(TEACHING_SEQUENCE_SCHEMA));

        // 3. 解析并验证 JSON（schema 校验）
        TeachingSequenceJson seq = parseAndValidate(response.getContent());

        // 4. 存入 teaching_sequences 表
        ctx.setTeachingSequenceJson(seq);
        return EnrichmentResult.ok();
    }

    @Override
    public boolean isCritical() { return false; } // 非核心，失败降级
}
```

#### DiagramStep（Order 9，替换现有简陋版）

```java
@Component
@Order(9)
public class DiagramStep implements EnrichmentStep {

    private final DiagramTypeClassifier classifier;

    @Override
    public String getName() { return "diagram"; }

    @Override
    public boolean isApplicable(EnrichmentContext ctx) {
        return ctx.getProblem() != null;
    }

    @Override
    public EnrichmentResult process(EnrichmentContext ctx) {
        // 1. 识别算法类型
        DiagramType diagramType = classifier.classify(
            ctx.getProblem(), ctx.getPolishedContent());

        // 2. 选择对应 Prompt 模板
        String templatePath = "diagram/" + diagramType.templateName() + ".txt";

        // 3. 生成图解内容
        String prompt = templateEngine.render(templatePath, buildVars(ctx));
        AiResponse response = smartRouter.route(new AiRequest()
            .setContent(prompt).setType(RequestType.DIAGRAM_GENERATION));

        // 4. 解析输出（Mermaid 源码 or 结构 JSON）
        DiagramContent content = DiagramParser.parse(
            response.getContent(), diagramType);

        ctx.setDiagramContent(content);
        return EnrichmentResult.ok();
    }

    @Override
    public boolean isCritical() { return false; }
}
```

## 八、安全与错误处理

### 8.1 AI 生成内容校验

```java
public class TeachingSequenceValidator {

    public ValidationResult validate(String json) {
        // 1. JSON 格式校验
        TeachingSequenceJson seq = parseJson(json); // throws if invalid

        // 2. Schema 校验
        if (seq.getSteps() == null || seq.getSteps().isEmpty())
            return ValidationResult.fail("steps 不能为空");
        if (seq.getSteps().size() != seq.getTotalSteps())
            return ValidationResult.fail("totalSteps 与实际 steps 数量不一致");

        // 3. 步骤内容校验
        for (TeachingStepJson step : seq.getSteps()) {
            if (step.getNarration() == null || step.getNarration().getText().isBlank())
                return ValidationResult.fail("步骤 " + step.getStep() + " 解说为空");
            if (step.getAnimations() == null || step.getAnimations().isEmpty())
                return ValidationResult.fail("步骤 " + step.getStep() + " 无动画指令");
        }

        // 4. 内容安全校验（blacklist）
        if (blacklistLoader.containsBlacklistWords(json))
            return ValidationResult.fail("内容包含违禁词");

        return ValidationResult.ok();
    }
}
```

### 8.2 前端降级策略

| 情况 | 降级方案 |
|------|---------|
| 走流程数据加载失败 | 显示空状态 + "查看解析文字" 按钮 |
| 特定渲染器不支持 | 降级到通用文字步骤列表（无动画） |
| 自定义输入超时（>60s） | 提示超时，恢复标准例子 |
| 用户设备性能不足 | 检测帧率，低于 30fps 自动降为静态图 |

```typescript
// 性能检测
const checkPerformance = async () => {
  const frames: number[] = [];
  let last = performance.now();
  for (let i = 0; i < 60; i++) {
    await new Promise(r => requestAnimationFrame(r));
    frames.push(performance.now() - last);
    last = performance.now();
  }
  const avgFps = 1000 / (frames.reduce((a, b) => a + b) / frames.length);
  return avgFps < 30 ? 'low' : 'normal';
};
```
