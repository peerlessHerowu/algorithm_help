## 一、产品定位

面试模拟的核心不是"测试是否会做题"，而是训练三种能力：

1. **时间压力下的稳定性**：限时环境暴露真实表现
2. **沟通能力**：面试官评分60%看表达，不只是代码
3. **追问应变**：Follow-up 变体往往比原题更考察理解深度

## 三、后端实现

### 3.1 数据模型

```sql
CREATE TABLE interview_reports (
    id              VARCHAR(36)  PRIMARY KEY,
    user_id         BINARY(16)   NOT NULL,
    problem_id      VARCHAR(100) NOT NULL,
    session_id      VARCHAR(36)  COMMENT '关联交互会话',

    -- 配置
    difficulty      ENUM('easy','medium','hard','random') NOT NULL,
    time_limit_min  TINYINT      NOT NULL DEFAULT 45,
    company_style   VARCHAR(20)  COMMENT 'google/meta/bytedance/general',

    -- 结果
    total_score     TINYINT      COMMENT '综合得分 0-100',
    correctness     TINYINT      COMMENT '正确性 0-100',
    code_quality    TINYINT      COMMENT '代码质量 0-100',
    efficiency      TINYINT      COMMENT '效率分析 0-100',
    communication   TINYINT      COMMENT '沟通表达 0-100',

    -- 内容
    strengths_json  JSON         COMMENT '优点列表',
    improvements_json JSON       COMMENT '改进建议 {dimension: advice}',
    followup_problems JSON       COMMENT 'AI 生成的 Follow-up 变体题',

    -- 时间
    actual_duration_ms INT       COMMENT '实际用时（毫秒）',
    completed_at    BIGINT       NOT NULL,
    created_at      BIGINT       NOT NULL,

    INDEX idx_user (user_id, completed_at DESC)
) ENGINE=InnoDB COMMENT='面试模拟评分报告';
```

### 3.2 面试评分 Prompt

```java
private String buildScoringPrompt(InterviewSession session) {
    return """
        你是一位资深算法面试官，请对以下面试录像进行综合评分。

        ## 题目
        %s

        ## 面试对话记录
        %s

        ## 用户提交的代码
        ```%s
        %s
        ```

        ## 评分维度（每项 0-100）
        1. **正确性**：解法是否正确？边界情况处理是否完整？
        2. **代码质量**：代码规范性、可读性、是否有明显可优化点？
        3. **效率分析**：是否能正确分析时间/空间复杂度并解释原因？
        4. **沟通表达**：思路表达是否清晰？面对追问是否能有条理回应？

        ## 输出格式（严格 JSON）
        {
          "totalScore": 82,
          "correctness": 88,
          "codeQuality": 85,
          "efficiency": 80,
          "communication": 75,
          "strengths": ["思路清晰", "代码规范"],
          "improvements": {
            "communication": "建议先解释为什么选这个方案，再描述实现",
            "efficiency": "缺少对最坏情况的详细分析"
          },
          "followupProblems": ["最接近的三数之和", "四数之和"]
        }
        """.formatted(
            session.getProblemTitle(),
            session.getFormattedDialogue(),
            session.getCodeLanguage(),
            session.getSubmittedCode()
        );
}

### 3.3 AI 代码审查（不执行代码）

```java
@Component
public class InterviewChatHandler implements WebSocketMessageHandler {

    @Override
    public String getType() { return "INTERVIEW_CHAT"; }

    @Override
    public void handle(WebSocketSession ws, WSMessage msg) {
        String action = (String) msg.getPayload().get("action");

        if ("AI_REVIEW_CODE".equals(action)) {
            String code = (String) msg.getPayload().get("code");
            String lang = (String) msg.getPayload().get("language");

            String prompt = """
                你是一位严格但公平的面试官，请审查以下代码的正确性：
                
                题目：%s
                
                ```%s
                %s
                ```
                
                请指出：
                1. 逻辑是否正确（是/否 + 原因）
                2. 是否有 bug（如有，指出具体位置和原因）
                3. 边界情况处理（列出已处理和未处理的边界）
                4. 一句话总体评价
                
                语气：简洁直接，像面试官在给即时反馈。
                """.formatted(session.getProblemTitle(), lang, code);

            // 流式输出到 WebSocket
            smartRouter.routeStreaming(prompt, chunk -> sendChunk(ws, chunk));
        }

        if ("FOLLOWUP".equals(action)) {
            // AI 面试官追问
            generateFollowup(ws, msg, session);
        }
    }

    private void generateFollowup(WebSocketSession ws, WSMessage msg,
                                   InterviewSession session) {
        String companyStyle = session.getCompanyStyle();
        String prompt = buildFollowupPrompt(session, companyStyle);
        smartRouter.routeStreaming(prompt, chunk -> sendChunk(ws, chunk));
    }

    private String buildFollowupPrompt(InterviewSession session, String style) {
        String styleInstruction = switch (style) {
            case "google" -> "侧重系统设计延伸：'如果数据量扩展到10亿，你的方案如何调整？'";
            case "meta"   -> "侧重代码优化和边界：'有没有更节省空间的写法？'";
            case "bytedance" -> "侧重快速迭代：'如果时间缩短到 O(n log n)，能做到吗？'";
            default -> "通用追问：复杂度分析、边界情况、优化思路";
        };
        return """
            你正在主持 %s 风格的算法面试，候选人解答了「%s」。
            %s
            根据候选人当前的回答，提出一个针对性的追问（1-2句话，简洁）：
            """.formatted(style, session.getProblemTitle(), styleInstruction);
    }
}
```

## 五、面试→复习联动

```java
// 面试结束后自动加入复习计划
@EventListener
public void onInterviewComplete(InterviewCompleteEvent event) {
    InterviewReport report = event.getReport();

    // 自动创建复习卡片
    SpacedRepetitionCard card = SpacedRepetitionCard.builder()
        .userId(report.getUserId())
        .problemId(report.getProblemId())
        .cardType(CardType.EXPLAIN)
        .source(CardSource.INTERVIEW)
        .metadata(Map.of("interviewScore", report.getTotalScore()))
        // 高分（≥80）初始间隔3天，低分1天
        .intervalDays(report.getTotalScore() >= 80 ? 3 : 1)
        .nextReviewAt(now() + report.getTotalScore() >= 80
            ? DAYS_3_MS : DAYS_1_MS)
        .build();

    cardRepo.upsert(card);  // 已存在则不重复创建
}
```
