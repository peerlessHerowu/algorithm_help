## 二、Phase 0: MVP 详细规划

### 2.1 MVP 目标

> 用最小成本验证："AI生成的算法深度解析"质量是否足够好、是否对自己有帮助。

### 2.2 MVP 范围

**做**：
- 50道经典题目的深度解析（L2+L3级别）
- 每题包含：多解法+逐步流程+图解+复杂度+模式标签
- CLI工具：输入题号→生成完整解析Markdown
- 解法对比与底层框架提炼
- 本地浏览（Markdown直接阅读或简单静态站）

**不做**：
- 用户系统、数据库
- 实时交互（费曼模式等交互功能暂不做）
- 面试模拟、间隔重复
- 多端适配

### 2.3 MVP 技术选型

| 层 | 选择 | 理由 |
|----|------|------|
| AI生成 | Kiro（当前IDE） | 零成本、质量高 |
| 存储 | 文件系统(JSON+MD) | 零依赖、Git管理 |
| 浏览 | Markdown阅读器 / Astro静态站 | 极简部署 |
| 开发语言 | TypeScript (Node.js) | 后续复用 |
| 图解 | Mermaid | AI容易生成、渲染简单 |

### 2.4 MVP 50题选择标准

1. LeetCode HOT 100 中高频出现
2. 覆盖主要模式（每种模式至少3题）
3. 难度分布：Easy 10 / Medium 30 / Hard 10
4. 面试高频（大厂标签多的优先）

[揭示各解法的共同本质]

## 📊 图解
[Mermaid 图 / 逐步状态图]

## 🎯 模式标签
