# 算法深度理解引擎 — 功能全景盘点与规划

> 更新时间：2026-09-01 | 基于 PRD v1.0 + 6个 Kiro Spec + 实际代码/数据库扫描

---

## 一、产品全貌（先记住初心）

PRD 开篇一句话：**"用认知科学 × AI 重新定义算法学习体验——从直觉到论文，从刷题到实践，五级深度随你选。"**

这不是一个"AI 生成解析"工具，而是一个完整的**算法认知系统**，包含四大层：

```
┌────────────────────────────────────────────────────────────┐
│                    AI 算法深度理解引擎                       │
├──────────────┬──────────────┬──────────────┬───────────────┤
│  内容层       │  理解层       │  应用层       │  记忆层       │
├──────────────┼──────────────┼──────────────┼───────────────┤
│ 多平台题解聚合│ AI流程解析    │ 实际项目映射  │ 间隔重复      │
│ 链接解析导入  │ 智能图解      │ AI前沿应用    │ 模式识别测试  │
│ 评论精华提取  │ 多解法对比    │ 面试模拟      │ 变式练习      │
│ 错误检测纠正  │ 费曼式交互    │ 工作/人生映射 │ 算法直觉训练  │
│ 数学基础关联  │ 认知科学方法  │ 从LeetCode到  │ 复杂度直觉    │
│ 权威文献引用  │ Debug训练     │ Paper的路径   │ 学习小组      │
│ 多级别内容    │ 分级解释系统  │ 算法考古      │ 算法日历      │
└──────────────┴──────────────┴──────────────┴───────────────┘
```

PRD 定义了 **16 个模块（M1~M16）**，Kiro Spec 覆盖 5 个方向：
内容生成引擎、内容丰富 Pipeline、Web 展示层、交互功能层（33个需求）、知识图谱高级层（18个需求）。

## 四、整体完成度评估

按 PRD 的 16 个模块统计：

| 维度 | 数量 | 占比 |
|------|------|------|
| ✅ 已实现可用 | 框架+基础设施 | ~20% |

| ❌ 完全缺失 | M8细节/M12细节/M13部分 | ~15% |

**一句话总结：产品骨架已立（5级分解框架 + 交互式学习入口 + 知识图谱结构），但核心差异化功能（流程图解、走流程体验、真实题解素材、数学关联、论文桥梁）几乎全部缺失或数据为空。**

## 五、分阶段实施规划

### 原则

1. **先补地基**：爬虫素材 → 让 Pipeline 真正基于高赞题解工作，这是整个产品价值的基础
2. **先深度后广度**：把 30 道经典题做到真正的"深度理解"，好过 2767 道都是浅层 AI 生成
3. **先核心差异化**：M2（走流程）+ M3（图解）才是产品区别于 ChatGPT 的根本，优先实现
4. **数据和功能并行**：填充种子数据不是工程任务，和功能开发同步推进

## 六、最紧急的三件事

从所有分析来看，**现在最影响产品价值的三件事**，按优先级：
