## 一、产品定位与核心问题

### 1.1 为什么这是地基

整个产品价值链如下：

```
真实高赞社区题解（crawled_solutions）
    ↓
AI 纠错 + 润色 + 分级精炼（pipeline）
    ↓
有来源依据的高质量解析（enriched_solutions）
    ↓
走流程 / 图解 / 交互（其他模块）
```

**如果第一步没有真实素材，后续所有内容都是"AI 凭空生成"，等同于普通 ChatGPT，没有产品差异化。**

### 1.2 当前根本问题（事实）

通过数据库实测（2026-09-01）：
- `problems` 表：2767 题
- `crawled_solutions` 表：1540 条，覆盖 **154 题**（仅 5.6%）
- 高频题（`add-two-numbers`、`reverse-linked-list` 等）无爬取数据
- Pipeline 大量走 `nosource` 路径（AI 自主创作），偏离产品初心

### 1.3 目标状态

| 指标 | 当前 | 目标（Phase 0） | 目标（V1.0） |
|------|------|----------------|-------------|
| 爬取覆盖题目数 | 154 | 500（Top 500高频） | 1500 |
| 每题平均题解数 | 10 | 5（高质量筛选后） | 5-8 |
| Pipeline 有素材率 | ~5% | >90%（热门题） | >60%（全题） |

| 单题全级别覆盖（L1-L5）| <1% | 30%（Top 100题） | 60% |

### 3.4 爬取质量预评分规则

在存入 `crawled_solutions` 前，Python 端做轻量预评分：

```python
def pre_score_solution(solution: dict) -> float:
    score = 0.0
    content = solution.get('content', '')
    vote_count = solution.get('vote_count', 0)

    # 字数（200-5000 字为佳）
    word_count = len(content)
    if 200 <= word_count <= 5000:
        score += 0.25
    elif word_count > 100:
        score += 0.10

    # 有代码块
    if '```' in content or '<code>' in content:
        score += 0.25

    # 有图片或 ASCII 图
    if '![' in content or '```\n' in content:
        score += 0.10

    # 点赞数（对数归一化）
    import math
    if vote_count > 0:
        score += min(0.30, math.log10(vote_count + 1) / 4)

    # 有复杂度分析
    if 'O(' in content or '时间复杂度' in content or 'Time Complexity' in content:
        score += 0.10

    return min(1.0, score)
```

### 3.6 Python 爬虫核心逻辑

```python
# crawler/src/leetcode_crawler.py

import requests
import time
from typing import List, Dict
import hashlib

LEETCODE_SOLUTION_API = "https://leetcode.cn/graphql/"

SOLUTION_LIST_QUERY = """
query problemSolutions($questionSlug: String!, $skip: Int!, $first: Int!, $orderBy: TopicSortingOption) {
    questionSolutionArticles(
        questionSlug: $questionSlug,
        skip: $skip,
        first: $first,
        orderBy: $orderBy
    ) {
        edges {
            node {
                id
                title
                content
                author { username }
                upvoteCount
                viewCount
                solutionTags { slug }
                createdAt
            }
        }
        totalNum
    }
}
"""

class LeetCodeCrawler:

    def __init__(self, cookies: str, rate_limit_per_min: int = 30):
        self.session = requests.Session()
        self.session.headers.update({
            'Cookie': cookies,
            'Content-Type': 'application/json',
            'User-Agent': 'Mozilla/5.0 ...'
        })
        self.interval = 60 / rate_limit_per_min  # 每次请求间隔

    def crawl_problem(self, problem_slug: str, max_solutions: int = 10) -> List[Dict]:
        """爬取一个题目的高赞题解"""
        solutions = []
        skip = 0
        batch_size = 5

        while len(solutions) < max_solutions:
            time.sleep(self.interval)  # 限速
            resp = self._query_solutions(problem_slug, skip, batch_size)
            edges = resp.get('edges', [])
            if not edges:
                break

            for edge in edges:
                node = edge['node']
                content = node.get('content', '')
                if len(content) < 100:  # 内容太少跳过
                    continue

                content_hash = hashlib.sha256(content.encode()).hexdigest()

                solutions.append({
                    'problem_id': problem_slug,
                    'platform': 'leetcode-cn',
                    'platform_id': node['id'],
                    'title': node['title'],
                    'content': content,
                    'author': node['author']['username'],
                    'vote_count': node['upvoteCount'],
                    'view_count': node['viewCount'],
                    'source_url': f"https://leetcode.cn/problems/{problem_slug}/solutions/{node['id']}/",
                    'crawl_quality': pre_score_solution({'content': content, 'vote_count': node['upvoteCount']}),
                    'content_hash': content_hash,
                    'crawled_at': int(time.time() * 1000),
                })

            skip += batch_size
            if len(edges) < batch_size:
                break

        return solutions

    def _query_solutions(self, slug: str, skip: int, first: int) -> Dict:
        resp = self.session.post(LEETCODE_SOLUTION_API, json={
            'query': SOLUTION_LIST_QUERY,
            'variables': {
                'questionSlug': slug,
                'skip': skip,
                'first': first,
                'orderBy': 'MOST_UPVOTE'
            }
        })
        resp.raise_for_status()
        return resp.json()['data']['questionSolutionArticles']
```

## 四、内容精炼 Pipeline 优化

### 4.1 SourceFilterStep 优化（现有步骤）

当前实现：按票数排序取 Top 3，没有质量筛选。

优化后：

```java
@Override
public EnrichmentResult process(EnrichmentContext ctx) {
    List<Map<String, Object>> sources = ctx.getSources();
    int level = ctx.getTargetLevel();

    // 1. 过滤：content 太短（< 200字）的去掉
    List<Map<String, Object>> candidates = sources.stream()
        .filter(s -> {
            String content = getStr(s, "content");
            return content != null && content.length() >= 200;
        })
        .collect(Collectors.toList());

    if (candidates.isEmpty()) {
        log.warn("所有素材内容过短，退回全量");
        candidates = sources;
    }

    // 2. 综合评分排序：crawl_quality * 0.4 + 相关度 * 0.3 + 新鲜度 * 0.3
    candidates.sort((a, b) -> {
        double scoreA = computeScore(a, level);
        double scoreB = computeScore(b, level);
        return Double.compare(scoreB, scoreA);
    });

    // 3. 取 Top 3，确保解法多样性（不全是同一思路）
    List<Map<String, Object>> filtered = deduplicateByApproach(candidates, 3);

    if (filtered.isEmpty()) {
        return EnrichmentResult.fail("筛选后无可用素材");
    }

    ctx.setFilteredSources(filtered);
    log.info("素材筛选完成: 候选 {} 条 → 筛选后 {} 条", candidates.size(), filtered.size());
    return EnrichmentResult.ok();
}

private double computeScore(Map<String, Object> source, int level) {
    double quality = toDouble(source.get("crawl_quality"), 0.5);
    double votes = Math.log10(toDouble(source.get("vote_count"), 1) + 1) / 5.0;
    double contentLen = Math.min(1.0, toDouble(source.get("content_length"), 500) / 3000.0);
    return quality * 0.4 + votes * 0.3 + contentLen * 0.3;
}

/**
 * 按解法类型去重：不选同一 approach_tag 的多个
 */
private List<Map<String, Object>> deduplicateByApproach(
        List<Map<String, Object>> sources, int max) {
    List<Map<String, Object>> result = new ArrayList<>();
    Set<String> seenTags = new HashSet<>();

    for (Map<String, Object> s : sources) {
        if (result.size() >= max) break;
        String tag = getStr(s, "approach_tag");
        if (tag == null || seenTags.add(tag)) {
            result.add(s);
        }
    }
    return result;
}
```

## 五、内容质量评估系统

### 5.1 QualityScoreStep 评分细则

现有评分逻辑（规则式，0.0-1.0）已有基础，补充详细规则：

```java
/**
 * 结构完整性评分（权重 25%）
 * 检查：标题、摘要/简介、正文、复杂度分析
 */
private float scoreStructure(EnrichmentContext ctx) {
    String content = ctx.getPolishedContent();
    float score = 0f;

    // 有一级标题（# 开头）
    if (content.matches("(?s)^#\\s+.+")) score += 0.25f;

    // 有多个二级标题（结构层次）
    long h2Count = content.lines()
        .filter(l -> l.startsWith("## ")).count();
    if (h2Count >= 2) score += 0.25f;
    else if (h2Count >= 1) score += 0.15f;

    // 有 TIME_COMPLEXITY 和 SPACE_COMPLEXITY 标记
    if (content.contains("[TIME_COMPLEXITY]")) score += 0.25f;
    if (content.contains("[SPACE_COMPLEXITY]")) score += 0.25f;

    return Math.min(1.0f, score);
}

/**
 * 内容丰富度评分（权重 25%）
 */
private float scoreContentRichness(EnrichmentContext ctx) {
    String content = ctx.getPolishedContent();
    int level = ctx.getTargetLevel();
    float score = 0f;

    // 字数检查（按级别要求）
    int minLen = switch (level) {
        case 1 -> 400;
        case 2 -> 800;
        case 3 -> 1000;
        case 4, 5 -> 1500;
        default -> 600;
    };
    if (content.length() >= minLen * 2) score += 0.35f;
    else if (content.length() >= minLen) score += 0.20f;

    // 有代码块
    long codeBlocks = Arrays.stream(content.split("```")).count() / 2;
    if (codeBlocks >= 1) score += 0.25f;
    if (codeBlocks >= 2) score += 0.10f;  // 多个语言版本

    // 有 ASCII 图或列表（表格/列表）
    if (content.contains("│") || content.contains("┌") ||
        content.contains("+-") || content.contains("  →")) score += 0.15f;

    // 有具体数字示例（出现数字）
    if (content.matches("(?s).*\\d+.*→.*\\d+.*")) score += 0.15f;

    return Math.min(1.0f, score);
}

/**
 * 无跳步评分（权重 15%）
 * 惩罚项：包含"显然"、"容易得到"、"不难发现"等词
 */
private float scoreNoSkip(EnrichmentContext ctx) {
    String content = ctx.getPolishedContent();
    String[] skipWords = {"显然", "容易得到", "不难发现", "obvious", "clearly", "trivially"};

    long skipCount = Arrays.stream(skipWords)
        .filter(content::contains).count();

    if (skipCount == 0) return 1.0f;
    if (skipCount == 1) return 0.7f;
    return Math.max(0f, 1.0f - skipCount * 0.2f);
}

/**
 * 代码正确性评分（权重 25%）
 * 检查常见语法模式
 */
private float scoreCodeCorrectness(EnrichmentContext ctx) {
    String content = ctx.getPolishedContent();
    float score = 0f;

    // 有代码块
    if (!content.contains("```")) return 0f;

    // 代码有语法标记（python/java/cpp 等）
    if (content.contains("```python") || content.contains("```java") ||
        content.contains("```cpp") || content.contains("```go")) score += 0.30f;
    else score += 0.15f; // 有代码块但无语言标注

    // 代码包含函数/方法定义
    if (content.contains("def ") || content.contains("public ") ||
        content.contains("function ")) score += 0.30f;

    // 代码包含 return 语句
    if (content.contains("return ")) score += 0.20f;

    // 代码包含变量（有赋值语句）
    if (content.matches("(?s).*\\w+\\s*=\\s*\\w+.*")) score += 0.20f;

    return Math.min(1.0f, score);
}
```

### 5.2 自动发布阈值与人工审核流程

```
                  QualityScore

   0.0 ──── 0.4 ──── 0.6 ──── 0.8 ──── 1.0
           │         │         │
        REJECT    PENDING   PUBLISHED
        （自动     （人工      （自动
         拒绝）     审核）      发布）

REJECT（score < 0.4）：
  - 记录失败原因
  - 不写入 enriched_solutions
  - 触发重新生成（重试一次）

PENDING_REVIEW（0.4 ≤ score < 0.6）：
  - 写入 enriched_solutions，status=PENDING_REVIEW

## 六、内容多样性保障

### 6.1 DiversityCheckStep（现有步骤优化）

防止同题同级别生成多条内容高度相似的解析：

```java
@Override
public boolean isApplicable(EnrichmentContext ctx) {
    // 必须有 polishedContent，且数据库中已有同题同级别内容
    if (ctx.getPolishedContent() == null) return false;
    int existing = enrichedRepo.countByProblemIdAndLevelAndStatus(
        ctx.getProblem().getId(), ctx.getTargetLevel(), EnrichedStatus.PUBLISHED);
    return existing > 0;
}

@Override
public EnrichmentResult process(EnrichmentContext ctx) {
    // 计算与已有内容的相似度（基于内容哈希/关键词重合度）
    String newContent = ctx.getPolishedContent();
    List<EnrichedSolution> existing = enrichedRepo
        .findTop5ByProblemIdAndLevelAndStatus(
            ctx.getProblem().getId(), ctx.getTargetLevel(), EnrichedStatus.PUBLISHED);

    for (EnrichedSolution ex : existing) {
        float similarity = computeJaccardSimilarity(newContent, ex.getContent());
        if (similarity > 0.75f) {  // 75% 相似度阈值
            log.warn("新内容与已有内容相似度 {}，跳过保存", similarity);
            return EnrichmentResult.fail(
                "内容与已有解析相似度过高（" + (int)(similarity*100) + "%），请生成差异化内容");
        }
    }
    return EnrichmentResult.ok();
}

private float computeJaccardSimilarity(String a, String b) {
    Set<String> wordsA = tokenize(a);
    Set<String> wordsB = tokenize(b);
    Set<String> intersection = new HashSet<>(wordsA);
    intersection.retainAll(wordsB);
    Set<String> union = new HashSet<>(wordsA);
    union.addAll(wordsB);
    return union.isEmpty() ? 0f : (float) intersection.size() / union.size();
}
```

### 8.2 SSRF 防护

```java
@Component
public class UrlSecurityValidator {

    private static final Set<String> ALLOWED_DOMAINS = Set.of(
        "leetcode.cn", "leetcode.com",
        "nowcoder.com", "lintcode.com",
        "github.com", "codeforces.com"
    );

    public void validate(String url) {
        URI uri = URI.create(url);

        // 1. 只允许 HTTPS
        if (!"https".equals(uri.getScheme())) {
            throw new SecurityException("只允许 HTTPS 链接");
        }

        // 2. 域名白名单
        String host = uri.getHost();
        boolean allowed = ALLOWED_DOMAINS.stream()
            .anyMatch(d -> host.equals(d) || host.endsWith("." + d));
        if (!allowed) {
            throw new SecurityException("不支持的来源域名: " + host);
        }

        // 3. 禁止私有 IP（防 SSRF）
        InetAddress addr = InetAddress.getByName(host);
        if (addr.isSiteLocalAddress() || addr.isLoopbackAddress() ||
            addr.isLinkLocalAddress()) {
            throw new SecurityException("禁止访问内网地址");
        }
    }
}
```
