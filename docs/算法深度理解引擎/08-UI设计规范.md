# 算法深度理解引擎 — UI 设计规范

> 版本：v1.0 | 风格对标：Vercel Geist / Linear / Raycast
> 设计理念：**克制即高级，留白即呼吸，动效即灵魂**

---

## 一、设计哲学

### 1.1 三条核心原则

| 原则 | 描述 | 反面教材 |
|------|------|----------|
| **Less is More** | 信息密度克制，每屏只说一件事 | 满屏塞满信息的教育类网站 |
| **Content First** | 内容（代码、图解、解析）才是主角，UI 是配角 | 花哨的装饰抢了内容的戏 |
| **Quiet Confidence** | 自信但不张扬，细节处见功力 | 到处用渐变色和阴影 |

### 1.2 视觉气质关键词

```
精致 · 暗沉 · 工程感 · 呼吸感 · 锐利 · 静谧
```

整体给人的感觉：像一个精心打磨的专业工具，打开它就让人安静下来、进入心流状态。

## 二、色彩系统

### 2.1 暗色模式（主色调）

暗色模式为默认模式。设计优先暗色，亮色为适配。


#### 背景层级（从深到浅）

| Token | HSL 值 | 用途 | 视觉效果 |
|-------|--------|------|----------|
| `--bg-root` | `hsl(0 0% 4%)` | 页面最底层背景 | 近纯黑，沉稳 |
| `--bg-primary` | `hsl(0 0% 7%)` | 卡片/面板背景 | 微微浮起 |
| `--bg-secondary` | `hsl(0 0% 10%)` | 输入框/代码块背景 | 凹陷感 |
| `--bg-tertiary` | `hsl(0 0% 13%)` | Hover 状态/选中态 | 响应反馈 |
| `--bg-elevated` | `hsl(0 0% 15%)` | 弹窗/下拉菜单 | 最高层级 |

#### 文字层级

| Token | HSL 值 | 用途 |
|-------|--------|------|
| `--text-primary` | `hsl(0 0% 93%)` | 标题、正文主体 |
| `--text-secondary` | `hsl(0 0% 63%)` | 副标题、描述、占位符 |
| `--text-tertiary` | `hsl(0 0% 44%)` | 最弱信息、禁用态 |
| `--text-inverse` | `hsl(0 0% 7%)` | 亮色按钮上的文字 |

#### 品牌强调色（一个就够）

| Token | HSL 值 | 用途 |
|-------|--------|------|
| `--accent` | `hsl(220 70% 55%)` | 主按钮、链接、选中态高亮 |
| `--accent-hover` | `hsl(220 70% 62%)` | 主按钮 hover |
| `--accent-subtle` | `hsl(220 70% 55% / 0.12)` | 浅底色标签、subtle 背景 |
| `--accent-glow` | `hsl(220 70% 55% / 0.25)` | Glow 效果、focus ring |

> 为什么只用一个强调色？**克制是高级感的核心**。Linear 和 Vercel 都是单一强调色 + 灰度体系。

#### 语义色（仅在功能场景使用）

| Token | HSL 值 | 用途 |
|-------|--------|------|
| `--success` | `hsl(142 60% 45%)` | 已完成、已生成 |
| `--warning` | `hsl(38 90% 55%)` | 生成中、警告 |
| `--error` | `hsl(0 70% 55%)` | 失败、错误 |
| `--info` | `hsl(200 70% 55%)` | 提示信息 |

#### 难度色（算法题专用）

| 难度 | 颜色 | 设计说明 |
|------|------|----------|
| Easy | `hsl(142 55% 48%)` 翡翠绿 | 降低饱和度，不刺眼 |
| Medium | `hsl(38 85% 55%)` 琥珀黄 | 比橙更高级 |
| Hard | `hsl(350 65% 55%)` 玫瑰红 | 不用纯红，更有质感 |

### 2.2 亮色模式

亮色模式下反转背景层级，文字用深色。保持相同的强调色。

| Token | 暗色 | 亮色 |
|-------|------|------|
| `--bg-root` | `hsl(0 0% 4%)` | `hsl(0 0% 99%)` |
| `--bg-primary` | `hsl(0 0% 7%)` | `hsl(0 0% 100%)` |
| `--bg-secondary` | `hsl(0 0% 10%)` | `hsl(0 0% 96%)` |
| `--text-primary` | `hsl(0 0% 93%)` | `hsl(0 0% 9%)` |
| `--text-secondary` | `hsl(0 0% 63%)` | `hsl(0 0% 44%)` |

### 2.3 边框与分隔

| Token | 暗色 | 用途 |
|-------|------|------|
| `--border-subtle` | `hsl(0 0% 100% / 0.06)` | 卡片边框、分隔线 |
| `--border-default` | `hsl(0 0% 100% / 0.1)` | 输入框边框 |
| `--border-strong` | `hsl(0 0% 100% / 0.15)` | 选中态边框 |
| `--border-accent` | `hsl(220 70% 55% / 0.5)` | Focus 边框 |

## 三、字体系统

### 3.1 字体族

```css
--font-sans: 'Geist', 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
--font-mono: 'Geist Mono', 'JetBrains Mono', 'Fira Code', 'Consolas', monospace;
```

> Geist 是 Vercel 开源字体，兼具人文温暖和工程精度。如果用户环境无 Geist，降级到 Inter。

### 3.2 字号阶梯（基于 1.25 倍率）

| Token | 大小 | 行高 | 字重 | 用途 |
|-------|------|------|------|------|
| `--text-xs` | 11px | 16px | 400 | 标签、辅助信息 |
| `--text-sm` | 13px | 20px | 400 | 描述文字、卡片次要信息 |
| `--text-base` | 15px | 24px | 400 | 正文 |
| `--text-lg` | 18px | 28px | 500 | 小标题、卡片标题 |
| `--text-xl` | 22px | 30px | 600 | 页面子标题 |
| `--text-2xl` | 28px | 36px | 600 | 页面主标题 |
| `--text-3xl` | 36px | 44px | 700 | Hero 标题 |
| `--text-4xl` | 48px | 56px | 700 | 首页大标题 |

### 3.3 字重使用规则

| 字重 | 用途 | 频率 |
|------|------|------|
| 400 Regular | 正文、描述 | 70% |
| 500 Medium | 导航项、标签、按钮 | 20% |
| 600 Semibold | 标题 | 8% |
| 700 Bold | Hero 大标题 | 2% |

> 规则：**一个页面内最多出现 3 种字重**。字重越少，页面越干净。

### 3.4 字间距（Letter Spacing）

| 字号范围 | Letter Spacing | 说明 |
|----------|---------------|------|
| ≤ 13px | +0.01em | 小字适当加宽 |
| 14-20px | 0 | 正文保持默认 |
| ≥ 22px | -0.02em | 大字收紧更紧凑 |
| ≥ 36px | -0.03em | 超大标题更收紧 |

## 四、间距系统

### 4.1 基础间距（4px 为基数）

```
4  8  12  16  20  24  32  40  48  64  80  96  120  160
```

| Token | 像素 | 用途 |
|-------|------|------|
| `--space-1` | 4px | 图标与文字间距 |
| `--space-2` | 8px | 紧凑内边距 |
| `--space-3` | 12px | 标签内边距 |
| `--space-4` | 16px | 卡片内边距、组件间距 |
| `--space-5` | 20px | 段落间距 |
| `--space-6` | 24px | Section 内间距 |
| `--space-8` | 32px | 区块间距 |
| `--space-10` | 40px | 大区块分隔 |
| `--space-12` | 48px | 页面级区域分隔 |

| 区域 | 规则 |
|------|------|

| 段落间 | 24-32px |

| 卡片间 | 16px（紧凑）/ 24px（标准） |

## 五、圆角与阴影

### 5.1 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | 6px | 小按钮、标签 |
| `--radius-md` | 8px | 输入框、代码块 |
| `--radius-lg` | 12px | 卡片、面板 |
| `--radius-xl` | 16px | 弹窗、大卡片 |
| `--radius-full` | 9999px | 胶囊按钮、头像 |

> 规则：圆角统一偏大（8-12px），给人"柔和但精致"的感觉。避免 2-4px 的小圆角（太老派）。

### 5.2 阴影（暗色模式下极少使用）

暗色模式下用**边框 + 背景层级**代替阴影。亮色模式下才使用阴影。

```css
/* 仅亮色模式 */
--shadow-sm: 0 1px 2px hsl(0 0% 0% / 0.04);
--shadow-md: 0 4px 12px hsl(0 0% 0% / 0.06);
--shadow-lg: 0 8px 24px hsl(0 0% 0% / 0.08);

/* 暗色模式用 border 替代 */
--shadow-sm: none; /* 用 border-subtle 替代 */
```

## 六、动效系统

### 6.1 缓动函数

| Token | CSS 值 | 用途 |
|-------|--------|------|
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 元素出现（弹出、展开） |
| `--ease-in` | `cubic-bezier(0.7, 0, 0.84, 0)` | 元素消失（收起、隐藏） |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹性效果（Tab切换指示器） |
| `--ease-linear` | `linear` | 进度条、旋转动画 |

### 6.2 时长规范

| 时长 | 用途 |
|------|------|
| 100ms | 按钮颜色变化、opacity |
| 150ms | Tooltip 出现 |
| 200ms | Tab 切换、Hover 状态 |
| 300ms | 面板展开/收起 |
| 500ms | 页面进入动画 |

### 6.3 核心微交互

| 交互 | 动效描述 |
|------|----------|
| 卡片 Hover | Y轴上移2px + border变亮 + 微弱glow |
| 按钮 Hover | 背景亮度提升 + scale(1.02) |
| Tab 切换 | 下方指示条平滑滑动（spring缓动） |
| 代码块复制 | 图标变✓ + 绿色闪现 + 2s后恢复 |
| 页面加载 | 内容从下方fade-in + translate-y(8px) |
| 图表缩放 | 双指缩放跟手 + 惯性滑动 |

### 6.4 禁忌

- ❌ 不用旋转360度的loading（用脉冲条或骨架屏）
- ❌ 不用弹跳bounce效果（太卡通）
- ❌ 动画时长不超过500ms（超过就感觉卡顿）
- ❌ 不同时触发3个以上动画（视觉混乱）

## 七、组件风格定义

### 7.1 按钮

```
Primary:   白色文字 + accent背景 + 8px圆角
Secondary: text-secondary文字 + 透明背景 + border-default边框
Ghost:     text-secondary文字 + 无背景无边框（hover时bg-tertiary）
Danger:    error色文字 + 透明背景 + error色边框
```

按钮高度统一：32px（小） / 36px（标准） / 40px（大）

### 7.2 输入框

- 背景: `--bg-secondary`
- 边框: `--border-default`
- Focus: 边框变为 `--border-accent` + 外发光 `--accent-glow`
- 圆角: 8px
- 内边距: 12px 横向 / 8px 纵向

### 7.3 卡片（ProblemCard / PatternCard）

```
背景: --bg-primary
边框: --border-subtle（1px solid）
圆角: 12px
内边距: 20px
Hover: border变亮 + translateY(-2px) + 微弱上方阴影
```

### 7.4 LevelTabs（核心差异化组件）

**设计亮点**：不做普通的 Tab 条，做成「段落指示器」风格

```
容器: 一行排列，每个Tab是胶囊形状
未选中: 半透明背景 + text-secondary
选中: accent-subtle背景 + accent文字 + 左侧亮线(2px accent)
未生成: 虚线边框 + 锁图标 + opacity 0.4
过渡: 选中态切换时背景色渐变200ms
```

### 7.5 CodeBlock（代码块）

```
背景: --bg-secondary + 1px border-subtle
圆角: 8px
顶部: 语言Tab条（深灰背景，选中Tab有底部2px accent线）
代码: font-mono, 14px, 行高1.6
行号: text-tertiary, 右对齐, 固定40px宽
复制按钮: 右上角ghost按钮，点击后变✓绿色
```

### 7.6 MermaidRenderer（图表容器）

```
容器: bg-primary + border-subtle + 12px圆角
内边距: 24px
工具栏: 右上角浮动，半透明背景(glassmorphism)
全屏模式: 全屏蒙版 + 居中展示 + ESC关闭
导出按钮: ghost风格，hover时显示tooltip
```

### 7.7 DifficultyBadge

```
形状: 胶囊（border-radius: full）
大小: padding 4px 10px, font 11px, 字重500
Easy: 翡翠绿色文字 + 绿色/12% 背景
Medium: 琥珀黄色文字 + 黄色/12% 背景
Hard: 玫瑰红色文字 + 红色/12% 背景
```

## 八、布局规范

### 8.1 全局布局

```
┌──────────────────────────────────────────────────┐
│  Navbar (h=56px, fixed top, bg-root, border-b)   │
├──────────────────────────────────────────────────┤
│         │                            │           │
│ Sidebar │       Main Content         │   TOC     │
│ (w=240) │      (max-w=720px)         │ (w=200)  │
│         │                            │           │
└──────────────────────────────────────────────────┘
```

- Navbar: 56px 高，固定顶部，底部1px `border-subtle`
- Sidebar: 240px 宽，桌面端显示，移动端为抽屉
- Content: 最大720px（文本内容）/ 全宽模式1200px
- TOC: 200px 宽，固定右侧，仅桌面端显示

### 8.2 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| Mobile | < 768px | 隐藏Sidebar+TOC，底部Tab导航 |
| Tablet | 768-1024px | 窄Sidebar(60px图标模式)，隐藏TOC |
| Desktop | > 1024px | 完整三栏布局 |

## 九、图标系统

使用 **Lucide Icons**（Vercel/Next.js 生态首选），风格统一为：

- 线条粗细: 1.5px stroke
- 尺寸: 16px（内联）/ 20px（按钮内）/ 24px（导航）
- 颜色: 跟随 text-secondary，交互时跟随 text-primary

## 十、设计风格总结

**一句话定义**：深色沉浸 × 单色强调 × 精致微交互 × 工程师审美

这是一套给"喜欢 VS Code 暗色主题"的用户准备的设计。它不试图讨好所有人，而是让目标用户（算法学习者、工程师）感到"这是为我设计的"。
