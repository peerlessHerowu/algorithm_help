# Algorithm Help - 后续迭代待办

> 更新时间：2026-06-22

## 待纳入的功能（来自 math-helper 产品设计启发）

### 1. 教学动画播放器

**来源**：math-helper 的核心差异化功能，同样适用于算法讲解。

**场景**：
- 算法执行过程的分步教学（如快排的 partition、BFS 的逐层扩展）
- 数据结构操作动画（如红黑树旋转、堆的 sift-up）
- 复杂度分析的直觉建立

**核心能力**：
- 分步骤播放（不是连续动画，是"第1步→第2步→..."）
- 每步配同步文字解说（像老师在讲）
- 暂停/回放/变速/步骤跳转
- 从播放模式切到交互模式（自由探索）
- AI 追问集成（暂停后对当前步骤提问）
- 自动暂停点（关键步骤等用户确认理解）

**优先级**：中（当前 MVP 完成后的下一个大功能）

**注意**：与 math-helper 共享同一套播放器组件设计，后续抽为公共库。

---

### 2. 多主题系统（换肤）

**来源**：math-helper 会员功能设计。

**场景**：
- 用户根据审美偏好选择界面风格
- 深色/浅色不只是 dark mode，而是完全不同的设计语言
- 可作为会员权益差异化

**已准备的方案**：
- Apple 清透风（默认免费）
- Aurora 极光风
- Notion 文档风
- 3B1B 暗色系
- Brilliant 彩色风
- 黑板怀旧风
- 几何极客风

**技术实现**：CSS 变量换肤，内容结构不变，只切换视觉层。

**优先级**：低（MVP + 教学播放器之后）

---

### 3. 公共库抽取规划

当 math-helper 启动开发后，以下模块应抽为共享库：

| 模块 | 共享内容 |
|------|----------|
| AI 服务层 | AIProvider 接口 + SmartRouter + 各实现 |
| 教学播放器 | TeachingPlayer + AnimationRenderer 接口 |
| 主题系统 | ThemeDefinition + applyTheme |
| 前端组件 | CodeBlock, KaTeX Formula, SearchBar |
| 内容流水线 | 批量生成 + 审校 + 发布流程 |

建议时机：math-helper MVP 完成后，两个项目同时重构抽取。
